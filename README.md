# 👥 HR Workforce Analytics — Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Power BI HR Analytics Dashboard** designed to analyze workforce data and provide insights into employees, departments, compensation, hiring, training, performance, tenure, and attrition.

The dashboard presents important HR metrics through interactive KPIs, charts, slicers, and analytical visuals.


## 📁 Dataset

**Dataset Name:** Employee HR Dataset

The dataset contains employee-level information used to analyze workforce structure, salary, performance, training, hiring, tenure, and employee attrition.

## 🏗️ Data Model

The project uses an **EmployeeMaster** table as the main employee data source along with supporting date and analytical fields.

The dashboard includes calculated columns and DAX measures for workforce and HR analysis.

## 🎯 Key KPIs

| KPI                     | Description                           |
| ----------------------- | ------------------------------------- |
| **Total Employees**     | Total number of employees             |
| **Active Employees**    | Number of currently active employees  |
| **Average Salary**      | Average employee salary               |
| **Average Tenure**      | Average years of employee service     |
| **Attrition Rate**      | Percentage of employees who have left |
| **Training Investment** | Total training cost                   |
